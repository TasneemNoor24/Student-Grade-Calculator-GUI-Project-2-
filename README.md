# 🎓 Student Grade Calculator GUI (Java Swing)

This is a GUI-based Student Grade Calculator built using Java Swing.  
It allows users to enter marks for multiple subjects and automatically calculates total marks, percentage, and grade.

---

## 📌 Features
- 🧑 Student name input
- 📚 Subject-wise marks entry (Math, English, Physics, Computer, Urdu)
- 🧮 Automatic total calculation
- 📊 Percentage calculation
- 🏆 Grade system (A+, A, B, C, D, F)
- 🖥️ Clean and interactive GUI using Java Swing
- 🔄 Clear/reset functionality

---

## 🛠️ Technologies Used
- Java
- Swing (JFrame, JLabel, JTextField, JTextArea, JButton)
- Event Handling (ActionListener)
- Object-Oriented Programming (OOP)

---

## 🧮 Formula Used
- Total = Sum of all subject marks  
- Percentage = Total / 5  
- Grade based on percentage:
  - 90+ = A+
  - 80–89 = A
  - 70–79 = B
  - 60–69 = C
  - 50–59 = D
  - Below 50 = F
